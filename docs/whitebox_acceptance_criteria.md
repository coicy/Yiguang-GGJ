## B. 按钮与移动方块

运动前、中、后都要检查可见几何和实际碰撞。终点位置允许至多 1 个源数据像素的数值误差；该误差是本验收建议的工程容差，不改变设计尺寸。

| 编号 | 操作 | 通过条件 |
| --- | --- | --- |
| B01 | 从初始状态按 B1 | C1 顺时针旋转并停止。以已记录右下角铰点和 90° 为实现起点，但最终必须形成与相邻地面齐平的可用表面；角色能通过接缝，不悬空、不被台阶卡住。 |
| B02 | 从初始状态按 B2 | C2、C6 使用共同铰点刚性联动；整个过程中相对位置不变、不分离。终点解除它们对目标风通道的阻隔，原受遮挡位置恢复风力与风效。 |
| B03 | 从初始状态按 B3 | 只有关联的 C5 向下移动；终点上表面与目标地面齐平；无超调、反复下沉或遗留碰撞。 |
| B04 | 未按 B4 时尝试接近，再按 B4 | C3、C4 初始处于更高位置，玩家通过正常移动和可用能力不能触碰或钩住；触发后下降到 JSON 所示位置，成熟期可连接对应 Ring。 |
| B05 | 检查 C3、C4 下降时的 Ring | 若 Ring 附着于移动方块，显示与可钩挂位置随方块同步；不会提前留下可用的悬空锚点。具体附着关系在实施配置中显式记录。 |
| B06 | 运动中连续触发 5 次，并在停止后再次触发 | 无重复创建、运动叠加、越界、引用错误；最终行为符合实施时记录的触发策略。可逆性尚未确认，不以“再次按下必须复位”作为要求。 |
| B07 | 玩家站在移动面、靠近运动边缘时触发 | 碰撞随运动同步，不穿墙、不因瞬移被弹飞；没有永久卡住或无法重试的状态。若需要挤压致死规则，须另行定义。 |

“地面齐平”检查的是玩家行走表面，不只检查方块底边；“风不被阻隔”检查的是实际通路，不只检查旋转角度。若当前铰点与角度无法满足终点目标，应修正并记录几何方案，不把结果标为通过。
