## 2. 游戏定位

本作是面向 Windows 的单机横版 2D 动作游戏。玩家控制一株能够生长成人形的植物，结合近身战斗、平台探索与环境机关穿过失控温室。战斗强调灵活移动、清晰预警、连击衔接与主动反击；三形态能力决定探索路线。

核心体验是：

1. 观察敌人的准备动作和环境，选择接近、绕背、闪避或弹反。
2. 用轻击连段、重击破防或空中攻击抓住敌人的破绽。
3. 通过营养液成长、通过毒素枯萎，用三形态能力穿过平台和机关。
4. 在遭遇之间恢复与探索，死亡后从最近的安全点重试，最终击败守圃者并抵达出口。

## 3. 主角形态

主角拥有三个成长阶段。营养液推动主角向更大的阶段成长，毒素推动主角向更小的阶段枯萎。形态切换由资源吸收触发，而不是由固定顺序强制触发。

| 阶段 | 主要定位 | 核心能力 |
| --- | --- | --- |
| 幼芽期 | 小型通行与躲避 | 进入狭窄通道、躲避低位机关、进入隐藏支路；不能跳跃 |
| 人形期 | 灵活近战与机关操作 | 较短藤鞭、较快收招；奔跑、精准跳跃、扎根、伸长腿部 |
| 成熟期 | 较远距离战斗与空间探索 | 更长藤鞭、较慢收招；连接锚点、展叶滑翔、减缓下落并抵抗部分强风 |

### 3.1 幼芽期

幼芽期体型最小，重点解决尺寸限制和低位通路问题。它主要用于穿过缝隙、避开大型危险和探索隐藏支路，可用左键进行一次短距离地面前顶自卫。前顶先缩身蓄力，再向鼠标所在侧顶出并回弹；不提供连段、重击、闪避、弹反或空中攻击。战斗门不会把幼芽锁在必须击败敌人的场地中。幼芽期不能跳跃，关卡必须以其小体型可通行的路线提供推进方式。

### 3.2 人形期

人形期是最稳定的基础形态，承担近距离战斗、常规平台移动和机关操作。人形与成熟形态都能独立击败所有敌人，成熟不增加单次攻击伤害。

- **扎根**：固定在地面，抵抗风力、冲击或移动平台晃动。
- **伸长腿部**：扎根后让腿沿上下左右方向缓慢伸长，最多达到四个角色长度，并把主角沿伸长方向推出；腿可以在末端进行 90°转向，也可以触发高处机关。

### 3.3 成熟期

成熟期提供更强的空间交互能力，但不应替代其他形态的用途。

- **长藤蔓**：牵引远处机关、连接藤蔓锚点并进行摆荡移动。白盒中的 `Ring` 是可被成熟期长藤蔓钩住的环形锚点；只有成熟期可以使用该交互。
- **巨大叶片**：进行短距离滑翔、减缓下落，并抵抗部分强风环境。

## 4. 资源与形态转换

### 4.1 营养液

- 营养液用于促进成长。
- 主角持续吸收营养液，资源量达到当前阶段的成长阈值后，停止吸收并进入下一个成长阶段。
- 进入新阶段后，成长进度重新开始积累。
- 营养液也用于恢复毒素影响，并按照吸收量重新促进成长。

### 4.2 毒素

- 毒素不是单纯的惩罚资源，而是玩家主动枯萎、转换为更小形态的手段。
- 主角吸收毒素后，按当前阶段的枯萎阈值向更小阶段转换。
- 毒素主要分布在危险环境中，也可以通过少量特殊资源点参与形态路线选择。

### 4.3 吸收规则

- 资源吸收是连续过程，而不是一次性拾取。
- 达到当前阶段阈值时，立即停止当前资源的吸收并完成阶段变化。
- 阶段变化完成后，玩家才可以重新开始吸收资源。
- 营养液和毒素分别管理成长方向与枯萎方向，不混用同一套转化语义。

## 5. 毒素环境

毒素环境同时具有路径资源和环境风险两种属性。

- 身处毒素环境时，主角移动速度持续降低。
- 身处毒素环境时，当前形态的稳定度持续消耗。
- 离开毒素环境后，移动速度和稳定度逐渐恢复。
- 稳定度归零时，主角自动枯萎到更小的形态。
- 玩家可以主动利用毒素完成形态转换，但需要承担在毒区内行动的状态成本。

毒素环境的设计原则是让玩家在“是否借助毒素变小”和“是否继续停留以完成路线”之间做选择，而不是把毒素固定为纯粹伤害。

## 6. 平台、陷阱与机关

平台跳跃强调精准跳跃和路线判断，陷阱负责制造失误成本，机关负责要求玩家使用正确形态。

- 平台与陷阱应清晰表达安全区域、危险区域和可通行尺寸。
- 机关应至少有一种明确的形态关联，例如扎根稳定、伸长腿部触发、藤蔓牵引或叶片滑翔。
- 同一机关不应无理由要求多个形态；组合机制应服务于空间关系，而不是增加操作复杂度。
- 关卡的抽象目标是完成生态／科技装置的机关启动并打开出口；本文档不规定具体关卡实现方式。

## 7. 战斗与敌人

### 7.1 玩家战斗

- 人形与成熟形态共享三段轻击、地面重击、空中挥击、水平闪避与短窗口弹反。
- 成熟形态以更长距离换取较慢收招，伤害与人形相同；幼芽仅开放短距离地面前顶，伤害为 1，不破防，保留通行与探索定位。
- 三段轻击逐步增加击退，重击破除普通敌人的正面防护。攻击方向在起手时确定，当前动作不会随移动输入翻转。
- 闪避与弹反可取消攻击有效段之后的收招；连段允许预输入。空中攻击与空中闪避各自每次腾空限一次。
- 弹反仅接受角色前方的可弹反攻击；近战敌人失衡，孢子被反射。重砸用特殊姿势、红叉与声音说明不可弹反。
- 开始战斗动作会结束扎根、伸腿与挂藤，动作期间收起滑翔能力；受击、死亡和形态变化会清除残留动作与攻击判定。

### 7.2 敌人要求玩家做什么

| 敌人 | 核心行为 | 主要应对 |
| --- | --- | --- |
| 污染甲虫 | 蓄力后水平冲撞，撞空后停顿 | 跳过或闪避，转身反击；冲撞可弹反 |
| 孢子囊 | 固定位置鼓胀并发射慢速孢子 | 利用地形接近，或弹反弹体 |
| 修枝机兵 | 正面防护，挥刃后露出破绽 | 重击破防、绕背或弹反挥刃 |
| 守圃者 | 横扫、冲锋、不可弹反重砸；半血强化组合 | 看清首击预警后躲避，在收招或弹反失衡期间反击 |

敌人身体接触本身不造成伤害。精英不召唤杂兵，普通攻击不会中断精英的攻击流程。所有战斗都允许通过闪避与抓收招完成，弹反提高效率。

### 7.3 生命、重试和胜利

- 战斗生命独立于成长资源和稳定度。受伤不直接枯萎、不消耗成长进度。
- 玩家受击后有短暂无敌保护，避免一次接触连续扣血。
- 闪避只免疫战斗攻击；坠落与关卡即死危险仍然有效。
- 遭遇入口记录安全快照。死亡重置当前未完成遭遇与弹体，恢复战前形态和资源、补满生命；已完成遭遇在本次运行中保持完成。
- 击败守圃者后开启出口；进入出口才算通关。结果显示探索时间和重试次数，暂停不计入探索时间。

## 8. 设计边界

- 正式主关卡首次游玩目标为 10–15 分钟；这是待真实试玩校准的设计目标，不是已证明的通关时长。
- 三种形态都必须有不可被其他形态完全替代的用途。
- 资源转换必须服务于平台移动和机关解谜，不能发展成独立的复杂生存系统。
- 毒素既要提供主动形态转换价值，也要通过速度和稳定度消耗形成风险。
- 战斗与“形态选择 + 空间探索”共同构成核心体验；动作手感、敌人预警与关卡路线一起验收。
- 本版不加入装备、技能树、掉落养成、耐力条或联网。
- 开发按质量推进，不再受原 48 小时 Jam 工期上限约束；验收事实和未完成项见 [战斗验证记录](combat_validation.md)。

### 8.1 白盒实体约定

- `Ring` 表示藤蔓钩挂点，不是普通装饰物。
- 成熟期主角可用长藤蔓连接 `Ring`，连接后进入藤蔓摆荡/牵引流程。
