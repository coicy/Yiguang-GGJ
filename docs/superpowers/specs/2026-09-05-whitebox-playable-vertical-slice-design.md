# 白模可玩垂直切片设计

## 1. 目标

本次工作把现有白模接口和独立玩家组件整合成一个可以从开始正常操作到通关的 Godot 4.7.2 横版平台解谜关卡。交付范围一次性覆盖 GDD 中的三阶段形态、资源驱动的成长与枯萎、核心形态能力、检查点、死亡复活、机关和出口。

最终验收必须由操作者在真实游戏窗口中使用正常键盘输入完成整关，不允许调用调试方法、直接修改状态或跳过关卡段落。

## 2. 非目标

- 不引入正式美术、动画、音频或第三方插件。
- 不实现敌人、战斗、装备、存档、联网或多关卡选择。
- 不追求最终难度、最终数值平衡或正式关卡美术构图。
- 不建立通用能力框架；只实现本关所需的四个核心能力。

## 3. 架构

保留一个可复用的 `Player : CharacterBody2D`。形态切换不替换玩家场景，而是把变化分发给独立组件：

```text
Player
  CollisionShape2D
  Visuals (Node2D)
  StateMachine (Node)
  Movement (MovementController)
  FormController (FormController)
  ResourceController (ResourceController)
  AbilityController (AbilityController)
    LegExtension (Area2D)
  CameraTarget (Marker2D)
```

- `Player` 读取输入并负责组件接线。
- `MovementController` 拥有移动、跳跃、外力、扎根限制、藤蔓约束和滑翔运动。
- `FormController` 拥有当前形态的运行时副本，并通知碰撞、视觉、移动和能力组件更新。
- `ResourceController` 拥有成长进度、稳定度、营养吸收和毒素暴露。
- `AbilityController` 校验形态和状态，再启动或停止扎根、伸腿和藤蔓。
- 关卡拥有玩家实例、检查点快照、机关接线、复活和完成条件。
- HUD 只监听玩家和关卡信号，不直接修改玩法状态。

新组件使用 typed signal 向父节点报告事实，通过明确方法向下发送命令。跨场景只使用现有 `GlobalSignalBus` 生命周期信号。

## 4. 输入

| 输入 | 行为 |
| --- | --- |
| `A` / `D` | 水平移动；藤蔓连接时提供切向摆荡加速度 |
| `Space` | 跳跃；提前释放形成可变跳高；成熟期下落时按住进入滑翔 |
| 鼠标左键 | 人形期切换扎根/拔根；成熟期连接/断开最近藤蔓锚点 |
| `W/A/S/D` | 人形期扎根后，控制腿部伸长方向 |
| `R` | 从关卡初始状态重开 |
| `F3` | 显示或隐藏调试信息 |

现有 `switch_form` 输入不再用于普通玩法中的任意循环切换。强制切换只能作为 debug build 中的开发检查手段，且不可用于最终手动通关验收。

## 5. 形态数据

扩展 `FormDefinition`，让每种形态的数据资源定义：

- 移动速度、跳跃力度、重力倍率、最大下落速度和滑翔下落速度。
- 碰撞体宽高和白模颜色。
- 成长阈值。
- `can_root`、`can_extend_legs`、`can_use_vine`、`can_glide` 能力标记。

默认白模数值：

| 形态 | 碰撞尺寸 | 速度 | 跳跃 | 成长阈值 | 能力 |
| --- | --- | --- | --- | --- | --- |
| 幼芽 | `20 x 24` | 220 | -320 | 100 | 穿过矮通道 |
| 人形 | `28 x 40` | 300 | -400 | 120 | 扎根、伸腿 |
| 成熟 | `38 x 54` | 260 | -360 | 无 | 藤蔓、滑翔 |

切换形态时先检测新碰撞尺寸是否有空间。成长导致空间不足时暂缓切换并在 HUD 显示原因；离开阻挡区域后自动重试。枯萎到更小形态不会产生空间冲突。

## 6. 营养与毒素

`ResourceController` 使用范围 `0..100` 的稳定度，并维护当前阶段的成长进度。

- 营养区以每秒 40 点连续输入营养。
- 稳定度低于 100 时，营养先以每秒 50 点恢复稳定度，剩余输入才进入成长进度。
- 达到当前形态成长阈值后，立即停止本次吸收、升到下一阶段并清零成长进度。
- 毒区把移动速度乘以 `0.55`，并以每秒 35 点消耗稳定度。
- 离开全部毒区后，稳定度以每秒 20 点恢复。
- 稳定度归零时枯萎一级、恢复到 100，并清零当前成长进度。
- 幼芽稳定度归零时不再继续降级，但仍承受减速。

营养罐和毒区继续只负责范围检测与报告。玩家公开 `absorb_nutrition(amount)` 和毒素暴露入口，由 `ResourceController` 实际处理数值。

## 7. 形态能力

### 7.1 幼芽期

幼芽没有主动按键能力。较小的碰撞体让它能通过高度只允许幼芽进入的通道。白模视觉为绿色小型轮廓。

### 7.2 人形期：扎根

- 仅在落地且没有伸腿时允许启动。
- 扎根后水平速度归零、不能跳跃，并忽略风区施加的水平外力；左键再次点击拔根。
- 释放按键、离地、切换形态、死亡或重开时立即取消。
- 白模视觉显示向地面延伸的根线，并在 HUD 显示 `ROOTED`。

### 7.3 人形期：伸腿

- 仅在落地、未扎根且头顶伸展空间足够时允许启动。
- 扎根时按住 `W/A/S/D`，玩家停止水平移动，视觉沿输入方向伸长，并启用一个延伸 72 像素的 `Area2D`。
- 高位机关只接受该能力区域触发，普通玩家身体和其他形态不能激活。
- 释放按键、空间被阻挡、切换形态、死亡或重开时立即收回。

### 7.4 成熟期：藤蔓

- 点击鼠标左键时在 300 像素内选择最近且视线可达的 `VineAnchor`，再次点击断开。
- 连接后绘制白模藤蔓线，并把玩家限制在连接长度内；水平输入提供切向加速度，保留释放瞬间的速度。
- 超出范围、锚点失效、释放按键、切换形态、死亡或重开时立即断开。
- 没有合法锚点时不改变玩家运动，只短暂显示 `NO ANCHOR`。

### 7.5 成熟期：滑翔

- 仅在下落阶段按住 `Space` 时生效。
- 下落速度限制为形态资源中的 `glide_fall_speed`，不允许在上升阶段获得额外升力。
- 白模视觉展开两片叶状弧线，并在 HUD 显示 `GLIDE`。

## 8. 关卡交互

### 风区

`WindZone : Area2D` 按固定节奏在预警和吹风状态之间切换。吹风时向区域内玩家施加水平外力；扎根玩家忽略外力。区域颜色和文字随状态变化，保证无需音效也能读懂节奏。

### 机关与门

- 高位机关使用能力触发区，只接受人形伸腿区域。
- 最终低位机关位于幼芽通道内，只接受幼芽玩家本体。
- 每个机关激活后保持激活，驱动对应白模门关闭碰撞并改变颜色。
- 出口检测玩家进入；全部必要机关激活后调用关卡完成，否则显示 `机关未启动`。

### 检查点、死亡与复活

检查点首次触发时保存：玩家位置、形态 ID、成长进度、稳定度和机关状态。陷阱命中玩家后由关卡执行复活：取消全部能力、清空速度、恢复快照并移动到检查点。`R` 不使用检查点，完整恢复关卡初始状态。

## 9. 白模关卡流程

关卡为单一横向场景，使用色块、标签、碰撞形状和可移动白模门：

1. 幼芽从起点进入矮通道。
2. 在营养区成长为人形。
3. 通过有预警节奏的风区，在吹风阶段扎根避免落入陷阱。
4. 在高位机关下伸腿，打开第一道门。
5. 触发中段检查点，并在第二个营养区成长为成熟形态。
6. 跳跃后连接藤蔓锚点，摆荡越过宽缺口。
7. 释放藤蔓后滑翔到远端平台。
8. 进入毒区枯萎为幼芽，通过最终矮通道并激活低位机关。
9. 进入开放出口，显示通关界面与用时。

关卡尺寸、锚点范围、平台宽度和毒素速率优先保证机制稳定可读。每个新机制前提供就近检查点或安全地面，失败后可以快速重试。

## 10. HUD 与白模表现

HUD 显示：

- 当前形态名称。
- 当前阶段成长进度。
- 稳定度。
- 当前可用能力和按键。
- 扎根、伸腿、藤蔓、滑翔和毒区状态。
- 检查点、阻塞原因、出口状态和通关提示。

形态、危险、资源、机关、锚点和出口使用互不混淆的纯色。所有关键碰撞体都有对应可见白模，禁止只存在不可见逻辑区域。

## 11. 状态安全

- 所有能力都有统一 `cancel_all()`，在死亡、复活、形态切换和重开时调用。
- 同一帧只允许一次成长或枯萎转换。
- 多个毒区使用来源集合计数，离开一个区域不会错误清除其他区域的毒素状态。
- 藤蔓锚点无效时安全断开，不保留悬空引用。
- 检查点快照复制纯数据，不保存场景节点引用。
- 关卡完成具有幂等性，完成后停止计时并忽略重复出口触发。
- 任何能力条件不满足时保持原状态并给出短暂 HUD 提示，不抛出脚本错误。

## 12. 测试与验收

### 自动化测试

- `FormDefinition` 与 `FormController`：形态字段、深复制、合法切换和碰撞尺寸校验。
- `ResourceController`：连续营养、优先恢复稳定度、成长阈值、毒素减速、稳定度恢复和逐级枯萎。
- `AbilityController`：形态限制、扎根、伸腿、藤蔓选择/释放和统一取消。
- 场景测试：主关卡实例化玩家，矮通道、风区、高位机关、藤蔓、滑翔、毒区、低位机关、死亡复活、重开和出口完成均有可验证契约。
- 现有白模机关、区域和沙盒测试必须继续通过。

### 引擎验证

- Godot 4.7.2 headless 编辑器导入退出码为 0。
- 全部测试退出码为 0。
- 主场景 headless 启动退出码为 0，日志无 `SCRIPT ERROR`、`Parse Error` 或 `ERROR`。
- 可复用玩家场景和白模关卡分别通过当前场景启动检查。

### 实际操作验收

1. 启动真实游戏窗口。
2. 只使用鼠标左键、`W/A/S/D`、`Space` 和必要的 `R` 完成整关。
3. 操作过程中实际触发三次形态状态、扎根、伸腿、藤蔓、滑翔、毒素枯萎、检查点、机关和出口。
4. 到达通关界面，确认显示完成状态与用时。
5. 检查 Godot 日志无脚本错误，并确认 Git 工作区只包含本任务变更。
