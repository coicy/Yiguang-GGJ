# 失控温室音频制作与接入

2026-09-06。只接入正式手工主关卡及可复用角色；没有新增可玩的测试关卡。

## 声音方向

参考《空洞骑士》的有机、短促、可辨识反馈方向；制作方法参考 [Krotos / Foley Teacher 的重制演示](https://www.krotosaudio.com/foley-teacher-hollow-knight-sound-effects-reformer-pro/)，它是第三方重制讲解，不是 Team Cherry 原始工程分析。采用前端瞬态、材质层、低音量尾声的分层方式；不取用商业游戏原声，不复刻旋律。

本轮实际采用 CC0 现成声源的离线剪辑、滤波、变速和分层。没有调用生成式音频模型，不把 DSP 合成标成 AI 生成；现有工具不能直接让代理主观回听电脑声音。声音是否悦耳、是否符合画面、长时间是否疲劳，仍需人类试听。

## 身份与覆盖

| 类别 | 音色与实际事件 |
|---|---|
| 人形／成熟体 | 两套各五招：轻连击三段、重击、空中攻击；分别采用较轻快与较厚重的纤维／叶片／汁液组合。在攻击有效段开始播放，不在按键入队时播放 |
| 移动 | 草地、硬地、木质、金属四套脚步；按地形 TerrainSkin.material_id 选择，按移动速度调整步频；跳跃、按落地速度分层、闪避、滑翔展开与收拢、滑翔持续气流 |
| 植物能力 | 扎根、拔根、伸腿、回缩、藤蔓发射、可见挂接、脱离、藤蔓运动；营养与毒素吸收各自节流；成长、枯萎 |
| 污染甲虫 | 快速甲壳、木质咬合和短促生物声；发现、蓄力、冲锋／咬击、脚步、受伤、死亡 |
| 孢子囊 | 充压气泡、湿润组织和喷吐；发现、蓄力、近身鞭打、喷口释放、弹体碰撞爆裂、反弹、受伤、死亡 |
| 修枝机兵 | 棘轮、金属擦刃、链条；发现、普通／危险蓄力、斩击／突进／砸地、格挡、脚步、受伤、死亡 |
| 守圃者 | 低沉生物吼、粗木裂纹与重撞；发现、普通／危险蓄力、横扫／冲撞／重砸、过载转阶段、脚步、受伤、死亡 |
| 功能模组 | 按钮、能力开关、移动平台／方块启停与运动循环、战斗门开关、罐子吸收开关、毒区进入、荆棘、检查点、遭遇完成、死亡、重生、胜利、暂停菜单 |

字典含 101 个事件条目与 277 个短声变体，其中包括旧接口兼容条目、怪物通用后备和保留的危险提示。不是 101 种独立玩法，也不把同音变体算成新动作。另有 7 条循环和 5 首配乐。静态装饰、没有交互的墙体不持续发声。

## 配乐

探索曲保留 Dark Forest Theme；普通战斗与首领曲已替换。原 Battle Theme A 不再进入播放列表，其运行时文件已移除。

| 使用场合 | 曲目与作者 | 音色方向 |
|---|---|---|
| 探索 | Dark Forest Theme / The Cynic Project | 幽暗森林氛围 |
| 普通战斗变体一 | Battle Theme / Wolfgang_ | 紧张的管弦推进 |
| 普通战斗变体二 | Ghosts & Heroes，2025 loop / Bobjt | 弦乐、摇滚节拍与合成器 |
| 普通战斗变体三 | Heartfelt Battle，loop / request | 钢琴、弦乐与圆号 |
| 守圃者 | Epic Boss Battle [Seamlessly Looping] / Juhani Junkala | 独立的管弦首领战配乐 |

四首新下载的独立资源页均标注 CC0 1.0，署名、下载地址及作者循环标记见 assets/source/audio/music_manifest.json 与 docs/credits.md。音色描述来自作者资料，未冒称已经进行主观试听。

普通遭遇用随机袋轮换：三首各出现一次后重新打乱，跨轮也不连续重复。离开战斗后 3 秒内返回视为同一乐句的延续，不消耗新曲目。长战斗等实际 Ogg 播放器完成一整轮后再换到下一首。

音乐淡出后用 stream_paused 暂停解码器，不 stop；再次轮到同一曲目时从保留的位置继续。探索、首领以及检查点重试也保留进度。进度属于当前主场景生命周期，退出游戏后不会写入存档。暂停菜单只降音量，保持音乐时间连续；同一个模式的重复通知不换曲。

离线响度目标 -23 LUFS，44.1 kHz stereo Ogg。作者提供的三个循环版本保持原时长／节拍，只修正最后 3 ms 的数字接点；非循环的探索与 Wolfgang_ 曲目沿用 1.2 秒首尾交叠，不宣称其乐句已重新配器。运行时采用 1.2 秒振幅交叉淡变，避免对 dB 直接插值带来的中段音量塌陷；快速切换取消旧淡变，回调也确认曲目仍未激活后才暂停。暂停／死亡／胜利时音乐降低 12 dB。

## 混音与生命周期

- Master 只做最终限幅；SFX 压缩；Music、Ambience、UI 分总线。基础音量位于 default_bus_layout.tres、AudioPalette 和 GreenhouseSoundscape。
- 玩家自身声音居中。正式关卡共用 6 个全局通道与 16 个空间通道；敌人接入关卡声音池，死亡尾音不随敌人节点释放而中断。F6 单独敌人仍有本地后备池。
- 重要的受伤、危险、弹反优先于脚步；同事件设置冷却，同帧去重，随机变体不连续重复，轻微音高漂移不作用于单变体音乐提示。
- 世界声音按距离衰减与左右声像播放；超出 1200 像素不分配声道。空间通道暂停时暂停，UI 保持可用；音乐淡变忽略命中停顿的 time_scale。
- 重试清理短声、滑翔和机关循环。音频仅观察状态和信号，不改伤害、AI 时序或物理参数。
- GreenhouseLevel._ready() 配置空间池，不依赖关卡生成器保存额外属性。

## 制作和试听入口

- tools/build_audio.py：分层音效配方与完整构建工具；生成 recipes.json 和 features/audio/audio_palette.gd。不要直接修改生成的字典。
- tools/build_music.py：按 music_manifest.json 独立重建五首配乐及试听目录，不必重新生成短音效。
- assets/source/audio/：原始压缩包／音乐与逐素材来源记录。只在这里保留制作源，不进入游戏导出。
- assets/runtime/audio/designed/：实际播放文件。WAV 为 44.1 kHz mono PCM16，短音效可低延迟播放；长配乐为 Ogg。
- build/audio/listen.html：逐事件试听、筛选与变体比较；按游戏基础增益播放，未加入距离衰减和总线压缩。
- tools/check_audio.py：检查解码、削波、直流偏移、编辑边界、循环断点和变体是否相同。
- tools/capture_audio_mix.gd：从正式主场景的 Godot Master 总线录制代表性混音，包括实际玩家动作、空间池样本、音乐切换、重叠重音和暂停。样本段是编排的录音检查，不冒称完整关卡人工试玩。
- tests/scene/test_audio_system.gd：验证正式主入口接线、事件资源、声音池、四类音色身份、战斗／首领切换与重试。
- tests/scene/test_music_playback.gd：加载正式主场景与真实音频驱动，检查解码器续播、三首轮换、快速切换、菜单降音量、整曲循环换曲与首领重试。

制作依赖按 docs/toolkit.md 安装在被忽略的 build/audio/tools 中，不是游戏运行依赖。重新制作后用 Godot --editor --import --quit 导入，之后从默认 F5 启动。不能以客观测试通过替代主观听感验收。
