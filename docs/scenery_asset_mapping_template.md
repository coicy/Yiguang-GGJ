### 暂时无法可靠判断的素材

`_0009_图层-29.png` 是细长垂藤；`_0025_根部延申.png` 是需要定制碰撞的粗树根；`_0027_图层-57.png` 是平顶厚石板；`_0037_已插入图像.png` 与 `_0038_图层-53.png` 是可承重浮岛。`_0019_图层-58.png` 完全透明，禁用。

- `Ground` 的 Tile 只填写视觉 Tile、TileSet 来源、碰撞和单向平台属性，不把装饰图误登记为可站立地面。
- `Entities` 的素材填写实体主视觉；实体的触发范围、碰撞范围和 JSON 实例尺寸分开记录。
- 对 `B1–B4`、`C1–C6` 等已有白盒编号，优先在“关联实体 IID”或“备注”中保留编号，不改写 `data/Yiguang.json` 原始 IID。
- 中文文件名可作为临时素材名；确定长期使用后，再补充稳定的 Godot 资源路径或重命名方案。

## 六、Level 01 已实施映射

| 用途 | 运行时素材 | 配置方式 |
|---|---|---|
| 自然长地面 | `_0036_苔藓地1.png` | 多个地形实体拼接，等比 `0.28–0.40` |
| 石质平台 | `_0028_石板3.png` | 等比 `0.06–0.31`，独立矩形顶面碰撞 |
| 浮岛平台 | `_0037_已插入图像.png`、`_0038_图层-53.png` | 等比 `0.30–0.42`，顶面碰撞独立设置 |
| 硬地与墙体 | `_0030_锈蚀钢板-.png`、`_0031_水泥板.png` | 分区使用，墙面视觉旋转 90°，不缩放物理根节点 |
| 可移动机关 | 石板、藤条、树枝和苔藓块素材 | C1–C6 保持原宽高比，碰撞尺寸按机关用途独立设置 |
| 营养液 / 毒素 | `_0014_培养罐.png` / `_0018_锥形瓶.png` | 作为交互实体子 Sprite 等比缩放 |
| 背景 / 前景 | 草团、红花、树根、藤蔓和高草 | 无碰撞，按 Z 层摆放 |

树枝平台 `_0026` 的顶面不规则，本关卡只将其用于机关视觉；斜坡 `_0035` 未使用，避免矩形碰撞与画面轮廓不一致。
