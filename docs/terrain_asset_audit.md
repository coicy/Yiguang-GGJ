# 失控温室：现有地形与装饰资产审计

审计日期：2026-09-06。对象为当前工作区的原始 scenery PNG、runtime 图像和正式主关卡实际引用；本文是素材选择与补缺依据，不改变关卡几何、碰撞、玩法或素材文件。

## 审计结论

当前问题是地形结构部件不足与用途混用。现有图像中已经有草皮覆层、有限薄板、完整浮岛、树根承托、悬垂植物和实验器皿，但没有一套明确区分顶面、深截面、开放端头、转角、板底、承重连接和材质接缝的完整资源组合。仅继续增加同类草皮或换色地块，不能解决正式关卡的材料辨识与结构完整性。

当前 28 个 TerrainPiece 只使用 4 张图：6 处新厚岩土图、3 处旧锈蚀钢板、14 处旧苔藓薄台、5 处同一树枝。车间、庭院和核心共用锈蚀钢板，各区小台大量共用苔藓薄台；41 个前景植物只有高草1和红花1两种图，七区背景另各放一对相同树根与爬墙藤。七区的独立材料与设施特征尚未建立。

应先选用源文件库内未启用的 L 形根部承托、板底、坡形草地、垂坠植物和实验器皿。新增制作应针对现有资源无法承担的结构职责，避免再次生成已有完整枝体、普通草团、普通罐体或单纯换色的苔藓薄台。

## 七区独有材料组合与新增候选

下表只定义资源身份与用途，不规定关卡几何、台阶高度、障碍位置、碰撞或资产生成批次。新增项是功能候选：只有现有资源确实不能承担、并被正式设计选中后才进入制作。同一构件的左右端、打开／关闭状态、切片和色调调整不能分别冒充一种新材料。

| 区段 | 材料组合与识别依据 | 优先复用现有图 | 确实缺少的独特功能部件 | 防止重复生成 |
|---|---|---|---|---|
| ① 培养室 | 釉面培养槽／实验台 + 铜质承托 + 局部穿根；整洁设施包围新生植物 | 两种培养罐、量杯、锥形瓶、水泥／石板作为有限台座 | N1：有槽腔与唇缘的培养槽截面；N2：实验台铜质基脚／挂架连接件 | 不再生成第三套普通瓶罐；新槽必须提供容器／地面职责，不是石板换成浅绿 |
| ② 苔藓步道 | 草皮覆盖厚岩土 + 外露根与侵蚀断口；自然承重体积明确 | greenhouse_ground、草皮、树根1、L形根托、板下垂坠 | M1：岩土可见断口与草皮转入立壁的结构收口；必要的截面内填先从既有厚岩土适配 | 不重做第二张同职责整块苔藓厚地面；已有L根托先用，端头不能只是背景变透明 |
| ③ 孢子廊 | 潮湿多孔基底 + 层状菌体承托 + 排水痕；与普通绿地从结构上区分 | 石板／板底作旧廊基座、疏藤和小藤作附生细节 | S1：有菌褶下缘的层架菌体结构；S2：带孔腔与泄水口的湿壁截面／有限设施面 | 菌体承担附生支撑，不能复制孢子囊敌人，也不能给苔藓地涂紫色 |
| ④ 修枝车间 | 透空格栅／钢梁 + 水泥设备基座 + 有限铆钉护板；连接关系可见 | 锈蚀钢板作设备护板、水泥板、两种板底 | W1：格栅踏面与有厚度侧梁；W2：金属承重梁／设备挂接接口 | 不继续生成满屏锈板贴图；踏面、侧梁、接口提供不同职责，不把铆钉颜色当变化 |
| ⑤ 树冠通路 | 实心树枝 + 枝叉／断面 + 根托 + 悬垂植物；完整生长关系 | 完整枝体、L形根托、横／纵垂坠、短长藤蔓 | C1：可读的Y形枝叉连接；C2：有木质断面与皮层收束的断枝端头 | 不重画已有完整横枝来凑数量；L形根托和下缘叶帘已经存在 |
| ⑥ 隔离庭院 | 破裂混凝土 + 密封槽／框架 + 渗出的根系；强调曾被封闭的结构 | 水泥板、板底、原始树根、少量现有荆棘候选 | Q1：带真实裂口／露出内部构造的隔离墙截面；Q2：带密封槽的门框基座／接地端 | 不把车间锈板或水泥板换色当隔离区；裂口改变结构，不能只是裂纹贴花 |
| ⑦ 温室核心 | 核心基座的放射承重肋 + 铜质根芯套环 + 外围旧石；仪式性结构与战场清晰度并存 | 共同温室远景、有限石板／板底、少量根系；已有守圃者外形不动 | K1：带承重肋和台缘的核心基座截面；K2：包覆巨大根芯的开口套环／基脚连接件 | 不生成放大版普通锈板或新的普通温室背景；核心地标是设施，不能像额外敌人或可攻击目标 |

## 复用与新增的去重规则

1. **先登记职责，再选图。** 每项资源记录材料、结构角色、允许重复的方向、完整端头、可连接对象。已有图能承担相同职责时优先适配，不以“风格更好”为由重新生成一套同物件。
2. **分清材料与切片。** 一个资源的顶面、内填、左右端、角件是可组合的部件；它们解决边界职责，不按颜色或裁切数计算“新增材质”。一个完整浮岛也不能因裁切成三块而称为三套地形。
3. **保留有限图形的端头。** 石板、树枝、圆砾、完整罐体都有明确边缘，不作为任意长条或深墙内部使用。需要无缝时必须另行证明接缝连续，不能根据文件名或资源组推断。
4. **新制作必须解决表中缺口。** N/S/W/C/Q/K候选需具备不同结构、承重或设施用途；同一地块换色、同罐换液色、放大现有根、再画普通温室全景均不满足新增地形职责。
5. **边缘检查先于接入。** 原图预览中，部分树枝／浮岛／苔藓砾块有浅边或条带；荆棘1与荆棘3更明显。应在透明棋盘及实际背景确认其透明信息与缩小时的表现，未确认的不按正式可用部件验收。本轮只记录，没有编辑图像。
6. **交互语义保持明确。** 现有资源罐、植物铜开关、铜藤环、灯笼检查点已有语义和状态。后续环境外观补支座／门框即可，不能让普通设施长出同样的可交互高亮。
