# 系统 API 文档

本文档目录记录白模核心系统的公共接口。代码中的公共类、方法、导出字段和 signal 必须与这里保持一致；修改公共 API 时必须同步更新对应文档，并在变更记录中说明兼容性影响。

## 文档索引

- `forms.md`：形态定义、形态控制、成长/枯萎和资源吸收。
- `player.md`：玩家、移动控制、能力定义和能力控制。
- `interactions.md`：机关、资源点、毒素区、陷阱、检查点和出口。
- `level.md`：白模关卡、重置和关卡完成边界。

## API 约定

- 公共方法使用 typed GDScript 签名描述；返回 `bool` 的方法必须明确失败条件。
- 公共 signal 使用过去时命名，并记录参数和触发时机。
- `Resource` 只描述配置；运行时可变状态放在控制器、状态对象或场景节点中。
- 外部系统通过公开方法下发命令，通过 signal 接收事实；禁止跨模块直接修改内部字段。
- 删除或重命名公共 API 时，必须在对应文档留下迁移说明。
