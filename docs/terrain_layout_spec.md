# 失控温室：正式地形布局规格

状态：**当前平直拼装方案已被用户否决，不作为正式地形规格继续扩展。** 以下坐标、测试和尺寸保留为旧战斗验证关卡的记录；新的空间设计以 hollow_knight_scene_review.md 的实际画面对照为依据。既有自动测试证明当前玩法可运行，不能证明场景品质达标。

## 1. 坐标、能力与不可改变的边界

所有坐标均为世界单位，X 向右、Y 向下。TerrainPiece 的 position 是左上角，piece_size 向右、向下展开。本文的“台面 y”指真实碰撞上沿，不能把贴图中心或美术偏移当成落脚点。

- **撤销旧限制**：七区旧横坐标、遭遇旧入口/出口位置和全关 y=400 不是用户要求，不再固定。保留七区内容、八场遭遇的教学顺序与三种普通敌人/精英；允许重新安排房间高差、入口方向、上下折返和回路。战斗房内的有效宽度、预警净空与玩家实际可达性在新布局中重新验证。
- 所有普通敌人只在地面水平移动，不具备跨越实体高台的跳跃逻辑。除孢子教学中明确作为掩体的实体花槽外，战斗主路保持连续、平坦、无坑。
- 支撑根系、斜撑和后景梁默认不产生碰撞。真正挡人、挡弹体的前景实体必须有对应轮廓与碰撞；不能用背景枝条制造不可见的墙。
- 当前场景采用现有 TerrainPiece。此次规格不要求替换地形系统或新建可玩测试地图。

## 5. 材料和几何的接口

各区需要与结构用途匹配的独立部件，但不能把相同地块反复生成后仅换色。此次几何所需接口如下，具体画风、来源与资产制作由艺术规格决定。

- 主地表上沿：始终对齐真实 y400；培养槽沿、土岸、花槽、金属走道、树根/木面、隔离石台、核心台基各有明确厚度和接缝逻辑。宽面由可拼接中段、左右端头与转接件组成，不能拉伸端头覆盖整个房间。
- 基础与承托：土岸用侧壁/露根托住；车间24厚走道用梁端、地脚和后景斜撑解释跨度；树冠每个落台用枝颈连接树干；庭院/核心用台基侧面收口。后景支撑不改变主平面碰撞。
- 通行边界：幼芽洞的顶棚上下沿、32高花槽的实体侧面、单向平台的薄上沿必须与碰撞一致。不要把厚重岩块画在可从下穿过的平台上，也不要把可挡子弹的花槽画成背景植物。
- 过渡点：区间接缝使用对应结构的桥接件、门槛、管道穿墙或根系侵入，主面仍平直。七区差异同时来自承重结构、开放/封闭轮廓和用途，不能只依赖背景色变化。
