# 精英怪：守圃者

本次只重做正式手工关卡「温室核心」的守圃者。默认入口仍是 `scenes/app/main.tscn → Level_main.tscn → level_01.tscn`，沿用原有精英遭遇、40 点生命、战斗门、检查点和出口流程。其他怪物的独立行为不由这次修改重写。

## 参考与取舍

- [Team Cherry：Hollow Knight's Mega May Update](https://www.teamcherry.com.au/blog/hollow-knights-mega-may-update)：官方记录强调战士亡魂各自具有不同武器、攻击和行动模式，也描述了假骑士的巨大体型与威胁感，以及通过试玩调整挑战的过程。由此提炼：精英需要独立的动作身份、可学习的规则和可验证的反制。
- [苔藓骑士战斗资料](https://hollowknight.wiki/w/Moss_Knight)：步进斩击可以衔接第二刀，最后一刀结束后有停顿；后撤后会依据距离续接近战或远程。这是社区对游戏行为的整理。借鉴其推进、连招和收招之间的交互关系，守圃者使用本项目已有的植物装甲和巨刃，动作与参数重新设计。
- [Supergiant：Hades 更新日志](https://www.supergiantgames.com/blog/hades-updates/)：官方为牛头人的 Bull Horn 连携补充起手提示，并修复攻击穿过障碍等问题。由此提炼：攻击越有压迫感，关键预兆、碰撞阻挡和阶段衔接越需要清楚。

以上是本次设计分析，不代表原作公开了相同的 AI 代码或参数。前期检索中的《绿色之径巡览》主要提供区域与角色氛围；具体招式依据以苔藓骑士资料和上述开发日志为准。

## 战斗身份

守圃者是一名会主动逼近的重甲近战精英。压迫来自逼近速度、覆盖不同高度的招式、有限的连续进攻，以及受击时仍然站得住的重量感。玩家可以诱导挥空、穿到背后、弹反、连续重击压垮架势，或诱使冲撞撞墙。

- 追击速度从原来的 52 调整为 108 像素/秒，采用加速启动；二阶段追击乘以 1.2。
- 首次接敌有 0.65 秒的撑盾与压低重心动作。
- 依据双方距离、高度、视线和招式冷却选招；不读取玩家按键。
- 开始蓄力后固定朝向，不能在挥刃途中转身追踪。背后目标要经过 0.28 秒踏脚转身才能再次进攻。
- 起手、攻击、收招各自完成；空挥也承担收招。失衡、失去地面、玩家死亡等才取消攻击。

## 招式参数

所有时长单位为秒，有效帧相对 `strike` 开始计算。配置唯一入口是 `features/enemies/data/warden_tuning.tres`，`warden.tres` 保留基础体型、生命和移动参数。

| 招式 | 选择条件 | 蓄力 | 攻击时长 / 有效段 | 收招 | 玩家应对 |
| --- | --- | --- | --- | --- | --- |
| 踏步横斩 | 地面近距离 ≤98 px | 0.48 | 0.34 / 0.10–0.23 | 0.65 | 闪出刀路、绕背或弹反 |
| 蓄势冲撞 | 130–385 px，前方地面可用，冷却完成 | 0.62 | 0.58 / 0.07–0.47 | 0.82 | 跳过、错身、弹反；诱导撞墙 |
| 裂地重砸 | ≤122 px，横斩后或持续贴近，冷却完成 | 0.80 | 0.40 / 0.17–0.26 | 1.00 | 红叉不可弹反；避开落点，二阶段跳过地波 |
| 蹬地上挑 | 前方 ≤112 px、高出32–146 px，冷却完成 | 0.52 | 0.38 / 0.11–0.25 | 0.82 | 不持续停在头顶；换位后惩罚收招，可弹反 |
| 反手追斩 | 二阶段横斩后，目标仍在正面135 px内 | 0.38 | 0.34 / 0.10–0.23 | 0.86 | 看到双刻标记后准备第二次应对，绕背可使追斩放弃 |

普通招式造成1点伤害，重砸造成2点。冲撞、重砸、上挑分别有2.8、2.9、2.2秒冷却。一次有效段对玩家最多结算一次伤害。

二阶段在半血时标记核心不稳，当前已预告的招式和收招继续完成，再用0.9秒过载动作引入变化。二连斩从第一刀蓄力开始显示双刻标记，第二刀仍有独立预兆；最多两刀，之后必须收招。重砸只在真正落地的有效帧发出两道地波，不能在起手或重复回调中提前/重复发射。

## 全身发力与受击

沿用现有 `warden_atlas.png`，拆出胸腹、头、两侧大腿/小腿、上臂/前臂、巨刃与盾。通过关节旋转和两段肢体求解组织动作；游戏物理仍由 `CombatEnemy` 的 `move_and_slide()` 统一执行。

| 动作 | 全身配合 |
| --- | --- |
| 待机与逼近 | 宽站姿；胸腹轻呼吸，头与双臂稍有延迟；步幅依据实际位移推进，支撑脚与摆动脚交替 |
| 横斩 | 后腿承重、髋部后移、肩与刀回收；髋先前送，躯干旋转带刃；前脚落地接住重量 |
| 冲撞 | 收刃、盾前送、屈膝后压，后脚刨地；蹬地加速，停止时压低重心并制动 |
| 重砸 | 抬刃、伸髋、前脚准备踏下；髋和肩向地面压下，双膝吸收冲击，武器停在落点后再收回 |
| 上挑 | 蹲低并收刃至身体下方；双腿伸展，躯干起身，肩肘带刃上挑 |
| 普通受击 | 核心向来力方向偏移，头反向滞后，盾臂震动，双脚展开接住冲击；重击幅度更大 |
| 弹反失衡 | 武器被向上弹开，躯干后仰，盾下垂，双腿分开支撑 |
| 撞墙 | 盾与肩挤回胸腹，身体反弹，膝部弯曲，随后重新站稳 |
| 死亡 | 膝盖屈服、躯干折下、武器落下、身体沉降；空中死亡仍通过物理落地 |

动作与判定使用同一 `WardenPose` 时间轴。斩击沿刀身和上一物理帧至当前帧的刀路采样；冲撞检测盾前的接触区域，重砸使用落点的地面区域。表现不通过改变生命或物理位置来伪造命中。收招从实际被中断/结束的姿势接续，避免失衡起身后突然跳回挥刀姿势。

## 玩家反制与公平边界

- **失衡值6点**：轻击累计1，重击累计3。两次持续重击或多次轻击可以破坏架势；2秒没有压力后按1.4点/秒恢复。身体上方六小刻显示累计压力。
- **失衡开口**：击破架势1.05秒、弹反1.1秒、撞墙1.15秒。命中失衡中的敌人不会重置失衡计时。
- **明确的空当**：反手追斩之后仍有0.86秒完整收招；绕到背后使未开始的追斩放弃，已出手的方向保持不变。
- **地形约束**：视线和命中检查均遵守 World 层阻挡；冲撞选择前检查地面，行动时检查下一步支撑；墙/战斗门产生撞击开口，缺失地面终止突进。
- **画面可读性**：起手标记放在身体侧上方，避开正式关卡精英血条；红叉与地面落点线提示不可弹反的重砸，刀光跟随刀尖，不盖住玩家。

## 文件职责

- `warden_behavior.gd`：感知、决策、动作承诺、阶段衔接、位移请求、失衡反应。
- `warden_move.gd` / `warden_tuning.gd` / `data/warden_tuning.tres`：只读招式与行为配置。
- `warden_pose.gd`：全身姿势与刀刃位置的确定性采样。
- `warden_visual.gd`：图集关节、脚步、短刀光、地面冲击和预兆。
- `combat_enemy.gd`：组件接线、唯一物理移动入口、伤害结算和遭遇事件转发。
