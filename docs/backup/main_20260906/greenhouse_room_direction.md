# 失控温室：房间方向与首间培养室施工记录

更新：2026-09-06。用户已授权按《空洞骑士》的场景结构重新执行。本文件以 [场景对照评审](hollow_knight_scene_review.md)、[LDtk 数据分析](terrain_ldtk_reference.md) 和当前角色资源为依据；第一培养室现已接入正式主场景并记录真实渲染。第2节七区拓扑与第3–6节初版放样方案保留作设计对照；当前几何、素材标定与采样镜头以第7节为准。其余六区仍是接续拓扑方向。

## 1. 空间目标与实施边界

把七区当成温室内部相互连接的房间，而非等高走道上的七组布景。路线应有收窄、展开、上行、下行、回望与捷径。每个战斗房可以保留足够平整的活动面，其入口、出口和房体仍由用途决定。

本轮先替换①的房腔、地形、成长点与镜头；在(760,400)接回当前苔藓入口，保持其余已接入战斗主线可继续运行。这个接点只为本轮整合，不是全关必须y400的规则。后续改②–⑦时，遭遇、检查点和镜头需按房间区域绑定；单纯按X判定区段无法支撑真正的上下叠置和折返。

## 4. 首间培养室：初版放样方案（保留作对照）

### 4.1 总体尺寸与连通

范围x=-160…760，主要脚面y530，地基延伸至至少y640。出生脚点(35,530)；主成长腔x250…700；营养罐(310,515)；后景母培养罐地标约(430,355)。右端(760,400)接回现有主线。

房间先用下面的实体边界和空气轮廓成立，再制作适配其形状的边界画；不是给现有矩形贴图补树枝。碰撞边界可以比美术毛边简洁，但内轮廓的转折位置必须一致。

| 部位 | 可施工坐标 | 用途与约束 |
|---|---|---|
| 左育苗腔脚面 | x=-120…110，y530 | 出生在完整凹腔中，左端闭合；无需跳跃到达根洞 |
| 低根洞 | x110…245，floor530，ceiling底497 | 按Root当前坐标净高实际33。若验收要求严格32，把底边改498；不能把530-497记录为32。美术不得画小凸起侵占净高 |

可用一个连续地基多边形表达台阶，顶边顺序为：(-160,530)→(430,530)→(430,480)→(535,480)→(535,435)→(640,435)→(640,400)→(760,400)，再由底边闭合到y640。独立组件装配时保持相同顶边，不在接缝留隐形小台阶。

### 4.2 顶部与根裹设施的内轮廓

顶部外体量可以在y180…260，但真正可见的内檐必须进入常用镜头。以下是一条从左侧育苗腔、垂根、洞顶，到右侧高拱的下边界建议，实体填在其上方：

(-120,400)→(-110,345)→(-50,308)→(20,322)→(70,360)→(95,420)→(110,497)→(245,497)→(250,420)→(270,350)→(295,315)→(350,280)→(440,252)→(530,255)→(610,280)→(666,300)→(700,304)→(760,304)。

这条轮廓产生左侧较低的育苗凹腔、135宽的低根洞和向右上展开的高腔。中间根裹设施从屋顶连下来，不是离地悬挂的矩形低棚；右侧实台从地基向上伸，形成与悬顶相对的空气空间。绘制时可以使长曲线更自然，但洞顶497/498、台面和出口净空是碰撞锚点，不能随画稿漂移。

左右内檐在y300…350附近进入画面；大拱顶最高处允许超出近景上缘，不能把所有可辨顶缘都留在屏外。后景母罐不是替代房腔的巨型插画，其外形与透视必须服从这条空气轮廓。

### 4.3 操作、成长和可达性

第一段流程固定为：幼芽出生 → 水平走过根洞 → 在高腔营养点按E成长 → 观察右上三级台肩 → 跳上或尝试Q伸腿 → 步行出门。首房不放强制枯萎；毒素与恢复循环留给后面的探索段。

成长罐未缩放Area横向范围286…334。考虑幼芽半径12和水平offset2，最早接触大致在玩家x272，此时与洞右端245已有27距离，成长后的左侧碰撞边也位于洞外。若整体放大Area，该余量会缩小，必须重新计算。成长点右侧保留约96以上的开放停留/起跳区；第一次吸收后仅变人形，后续成熟仍在指定安全点完成。

台阶是无水平缺口的连续实台。以满速并按住跳跃估算：从(360,530)起跳，落到第一级高度的下降段约0.50秒，对应x480；从(475,480)起跳，到第二级下降段约0.523秒，对应x601；从(590,435)起跳，到第三级下降段约0.563秒，对应x725。落点均在台面内部，约有34以上的右侧余量。低速起跳会缩短水平位移，现场仍需按真实输入验证，不能把这些解析值写成测试通过。

第三跳的成熟形态最高头顶约322，附近内檐约300，仍有约22净空；若美术/碰撞把右侧檐口压到330附近，会产生不必要的顶头。地表小根须、碎石与草只作美术，不进入上述步行/落脚碰撞。

若保留低位机关，幼芽只能通过身体接触或已支持的幼芽能力操作，不能要求它在根洞内按Q扎根。Q的可选展示点放在成长后、第一台肩之前。

A保持到幼芽接近洞口右端；当玩家中心越过x255并继续右移，约0.5–0.7秒平滑转到B，避免每帧紧贴角色而丢掉房间整体。相机移动期间角色不能被甩出边缘，回头时设置约40宽的迟滞区，避免卡在洞口切镜头。

在B中，拱顶最高部分可能出画，但两側内檐和地形台肩仍应勾出房腔。若需第一次完整展示母罐与高拱，可在穿洞后的安全位置短暂平滑拉到zoom2.0、center约(474,392)，可见X154…794/Y212…572，再回到B；这不是可达性的前提，也不能频繁夺取控制。直接保持2.5时，以A/B的实际画面边界施工，不为了看全世界坐标而无脑缩远。

当前HUD占据顶部两侧。关键窄口、成长站位、起跳和出口脚面全部应在其下方可读；顶缘的识别不能只靠藏在HUD后的一个角。底部操作条也不能遮住530脚面：上述相机把脚面放在屏幕620，给约653开始的操作条留出间隔。

### 明暗与素材边界

用三个主要明暗层先完成房间：近处房体/根团最暗，后景母罐和玻璃拱居中，活动空气是相对明亮且低细节的区域。以0黑、100白的相对明度筛选：房体大面约10–22；后景地标约25–35；空气约40–55；可踩上沿约45–60；高于70的亮点只少量用于成长资源和必要交互反馈。最终颜色仍依植物绿与旧温室材料统一，不照搬空洞骑士配色。

母罐(430,355)负责说明房间曾用于培养，画在后景并降低线条强度；它不能以与玩家同等粗重的边线遮满活动空气。初始镜头不放巨大叶片覆盖整个背景。角色附近、洞口和右上出口之间应保留连续明区；地形厚度由整体截面、根颈与设施基础解释，不能回到“矩形平台上贴枝图”的方式。

## 6. 首间施工与验收顺序

1. 在正式level_01中建立上面的地基与屋顶/根团轮廓，先看A/B两个实际镜头；接点仍为(760,400)。只要去掉道具仍看不出两腔、低洞与右上出口，就继续调整形状，不批量铺素材。
2. 放出生、首罐、必要机关与检查点；首罐Area保持48×48，过滤sprout。营养后、首次上台之前设置安全恢复位置；重试不能把已成长角色放回低洞内。
3. 实际验证幼芽从35水平走到310；人形和成熟分别完成三阶，不用闪避/藤蔓补距离；检查洞高、成长瞬间、第三跳头顶、出门和回望。
4. 接房腔定制边界画与低对比后景，再逐帧核对可踩轮廓。整张画的职责是服从这间房，不是把未定义的房体藏在一张通用背景里。
5. 在1280×720/zoom2.5记录A、刚穿洞、成长后B、第二级台肩和出口五个视图。两腔尺度、窄口、厚地基、右上方向与角色轮廓必须成立；之后才作为其余区域的制作样板。

以上是初版施工建议及解析筛选。第7节记录正式主场景接入后的实际数据，与初版坐标不同处以已落地数据为准；当前记录包含静态渲染审阅，不代替正常输入通行和人类试玩。
