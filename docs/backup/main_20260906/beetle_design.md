# 第一个小怪：污染甲虫

已直接替换正式主关卡中所有 `beetle.tscn` 实例的行为与表现，首遇仍为苔藓步道。F5 从 `scenes/app/main.tscn` 进入；没有另建可玩演示或测试关卡。继续使用已有甲虫图集。

## 性格和对抗方式

笨重、低重心、靠六足撑地和头角攻击。发现玩家时先抬头警觉；近身挑顶，中距离刨地蓄力冲撞。攻击开始后锁定方向，冲空仍完成动作并刹步。绕背、跳过冲撞、打断蓄力、弹反和利用墙体都是有效反制。

| 动作 | 准备 / 攻击 / 收势 | 有效命中时间（攻击阶段内） | 全身配合 |
|---|---|---|---|
| 近身挑顶 | 0.38 / 0.24 / 0.56 秒 | 0.045–0.16 秒；1 伤害 | 后移压低、后足撑开 → 后足蹬地、胸部上抬、头角挑出、前足抬起 → 前足落地承重、背甲回摆 |
| 刨地冲撞 | 0.60 / 0.48 / 0.78 秒 | 0.045–0.42 秒；1 伤害 | 后足交替刨地、躯干压缩 → 0.09 秒加速至 260、头部向前、甲壳滞后 → 撑足刹停、重心前移后回正 |
| 轻击破韧 | 0.65 秒硬直，落地后收势 | 仅韧性耗尽时取消攻击 | 命中方向决定缩身侧偏、头部回摆、前足补撑 |
| 重击破韧 | 0.70 秒硬直，落地后收势 | 削韧耗尽时触发 | 更大幅度的躯干后仰、头壳错相回摆、抬足失衡 |
| 被弹反 | 0.70 秒硬直 | 立即取消攻击 | 头角被掀起，前足离地，胸部打开，向后小幅腾起 |
| 撞墙 | 0.85 秒硬直 | 同一物理帧终止冲撞判定 | 头部挤回胸部、躯干压缩、六足撑宽、向后反弹 |
| 死亡 | 1.10 秒 | 立即取消伤害和受击 | 顺受力方向倾倒、六足折叠，身体保持连接，末段淡出 |

生命为 8，韧性为 30；未破韧的轻击只扣血、闪白，不打断出招。破韧后追打不刷新硬直，结束后满韧性并获得 0.75 秒抗削韧窗口；恢复与削韧配置见 [战斗设计](combat_design.md)。保留玩家现有伤害、弹反、闪避和反馈接口。每个攻击阶段至多造成一次命中，警觉、转身、蓄力、收势、受击和死亡没有攻击判定。

## AI 和动作所有权

- 警觉距离 300，脱战距离 410；失去视线 1 秒后恢复短距离巡逻。巡逻有停顿和转身，不隔墙锁定攻击。
- 水平距离 ≤ 49 时挑顶；78–210 时优先冲撞；冲撞独立冷却 2.6 秒。其余距离靠近，攻击要求高度差 ≤ 42。
- 转身耗时 0.24 秒，先落足再转向；蓄力、攻击和收势阶段不追踪玩家掉头。
- 冲撞前按 20 单位采样前方地面，移动时继续检查脚下与遭遇边界。断崖前结束冲撞；墙体碰撞采用 `move_and_slide` 后的实际结果。
- `BeetleBehavior` 保存感知、决策、冷却和运动请求；通过信号请求根节点转换状态。`CombatEnemy` 保留物理本体、生命、伤害查询及遭遇接口。其他物种继续原有实现。
- `BeetleTuning` / `data/beetle_behavior.tres` 提供专属参数；`data/beetle.tres` 提供生命、冲撞速度和通用反馈参数。运行时不修改共享资源。
- `BeetlePose` 定义重心、头部、甲壳和支撑姿态；`BeetleVisual` 用六条两段腿和躯干层级呈现。腿的步频由实际位移驱动，支撑阶段脚相对地面向后补偿。动作切换从上一姿态短暂混合，不改变碰撞体缩放。

## 验证与预览

已在 Godot 4.7.2 / OpenGL Compatibility 上执行：

- `tests/scene/test_beetle_behavior.gd`：近/中距离选招、蓄力无伤害、一次命中、方向锁定、冷却、转身、薄墙碰撞、断崖、失去目标后硬直结束、轻重受击、弹反、死亡去重；另逐帧检查左右朝向的全身姿态、有限变换、关节和碰撞隔离。
- `tests/scene/test_beetle_main.gd`：复用既有输入机器人，在正式单甲虫/双甲虫遭遇分别用人形和成熟形态完成，4 场均通过、零死亡。机器人读取敌人状态，该结果不代表真人难度与初见耗时。
- `tests/scene/test_combat_system.gd`：189 项既有战斗回归断言通过。
- 甲虫 F6 等价独立场景启动、默认主入口启动、正式首遇 OpenGL 捕获。

`tools/capture_beetle.gd` 可捕获真实组件姿态；`-- --main` 捕获正式首遇；`-- --reel` 导出原地动作拆解帧（30 FPS）。原地拆解展示骨架动作，冲撞位移与碰撞以正式首遇和物理测试为准。输出放在忽略的 `build/qa/beetle/`。

画面检查：蓄力识别、头/胸/甲壳发力层次、脚部支撑、死亡肢体连接均已逐帧检查。沿用既有图集，因此触须跟随头部整体转动，没有单独新增触须贴图。尚未进行真人手感验收。
