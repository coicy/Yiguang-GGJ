# 《空洞骑士》场景结构对照评审

日期：2026-09-06。依据用户最新要求，以《空洞骑士》的实际场景作为结构与完成度参照。本轮实际查看官方图片及当前三张主关卡截图，仅做评审，没有修改实现或生成美术。

**结论：当前培养室、树冠、核心三张图均不能作为正式场景样板继续批量装配。** 已有素材变化并未解决房间形状、功能落点与空间层次的问题。应停止在既有横向平台排列上继续堆材料，重新做镜头内的房间结构。

### A：平桥属于一个有目的地的空间

- **空白形状**：左侧与中间是大块开阔、较亮的空气和水域；右约三分之一被高大的近处岩壁/树体占据，空白空间在右端收束。
- **顶部与地面**：左上开放，右上是压入画面的巨大实体；平桥约在画面下三分之一处，细顶缘之下是镂空桥身与长柱，水面另在更低一层。
- **纵深**：近处桥与右侧实体轮廓锐利，后方植物体块柔和、对比低，桥柱之间可见水和远景。
- **功能位置**：角色和近战敌人共享清楚的桥面；桥面接入右侧带门洞的实体。承重、站立面和目的地处于同一个结构关系中。
- **引导**：桥的水平线终止于清楚的门洞；近处体块限制视野，亮背景托住双方动作，玩家不依赖悬浮提示识别这是一条通往建筑的桥。[图A](https://shared.fastly.steamstatic.com/store_item_assets/steam/apps/367520/ss_d5b6edd94e77ba6db31c44d8a3c09d807ab27751.1920x1080.jpg)

### B：顶部、两侧和地面先组成房腔

- **空白形状**：亮空气集中在中间，两侧拱形支撑与上方深色砖体将它收成有限的腔室；屏幕边缘没有同等强度地争夺注意。
- **顶部与地面**：拱柱、中央上部结构、悬链和连续石质地面都有可辨轮廓；地面下方是厚实且逐渐沉暗的块体。
- **纵深**：后方弯曲管状/岩层纹理较淡，柱与前景地面更深；角色附近光亮，结构仍清楚。
- **功能位置**：角色站在房腔中央的同一连续走面上，没有为了增加内容而塞入一排小高台。
- **引导**：中央垂直结构与光区把注意带到角色落脚处；顶部和侧壁已经说明“进入地下房间”，道具无需替房间解释用途。[图B](https://images.squarespace-cdn.com/content/v1/606d4deb4db8c15ea53b3624/1618899784323-BSA3OYSJ2D92C0TYQGWC/d32d6a5d966b3240086871cfc3f24a56_original.jpg)

### C：可走空间由暗壁、悬顶和水域共同塑形

- **空白形状**：左侧大块暗壁压入，顶部垂挂轮廓向下伸；较亮空间从中间向右展开，脚下由水域截断，不是贯屏的等高走廊。
- **顶部与地面**：悬垂植物与上方苔块构成不规则顶缘；右侧孤台具有完整厚度和较亮的苔面，下面没有继续铺一条通用地板。
- **纵深**：底部远处叶丛柔和，近处暗轮廓更重，局部光区让孤台与角色脱离背景。
- **功能位置**：截图可确认角色站在右側孤台上；上方苔块只作为可见轮廓记录，不能仅凭单帧断言它可站立。
- **引导**：平台的孤立位置、周围空隙与上方遮挡共同让玩家判断落点和探索方向。它不是在任意背景上等距摆放的目标标记。[图C](https://images.squarespace-cdn.com/content/v1/606d4deb4db8c15ea53b3624/1618899930590-LJTD63I9Q61WISRJB522/ee09c92b4fe43f04a3f7697dd103cb2a_original.jpg)

## 3. 应停止的方向与下一份样板要求

应停止继续把“全关共同主地面高度＋等宽横向房段＋新增材料”当成不可改变的前提。也不应给当前布局再套一层拱架、枝条或深色前景，便把它称为参考《空洞骑士》的房间。用户要求的是实际空间品质，这需要先改房间轮廓、通道关系和功能落点。

下一份样板应先用少量明暗块，在实际镜头中建立：

1. **培养室**：明确的设施内部、压低的根洞入口、穿出后的开口与成长落脚区；低通道是房体的一部分。
2. **树冠**：一条由主干和悬顶围出的上行/绕行空腔，主路线与落回下层的空隙清楚；平台由路线所需的位置决定，不再从对称三点开始布置。
3. **核心**：具有顶部、两侧入口/出口和中央结构关系的完整大房间；平坦战斗面置于该房间之内，预警净空明确。

在不看HUD、不靠场景标题、去掉小道具的情况下，应仍能区分三种房间、读出下一步方向，并认出角色当前站立面和可用空隙。达到这一步后才检查材料、植物和设施细节。已有战斗尺寸与可达性应作为物理验证条件重新检查，不能反过来成为保留当前拼装布局的理由。

本笔记没有宣布新布局已通过，也不提出用装饰挽救现有三张图的方案。
