# 第二个小怪：孢囊喷吐者

已接入正式主关卡孢子廊及既有混合遭遇，复用 `features/enemies/spore.tscn` 和现有孢子图集。F5 入口仍是 `scenes/app/main.tscn`；没有新增可玩的演示或测试关卡。

## 性格与反制

扎根、敏感、靠囊体积蓄压力的植物怪。根须支撑身体，远距离吸气喷吐；玩家贴近时先反向缩身，再甩出整个囊体。它不追赶玩家，不接触即伤。玩家可以利用花槽遮挡视线、跳跃接近、在收招时攻击，或弹反孢弹返还两点伤害。

## 自然招式与全身动作

| 动作 | 准备 / 攻击 / 收招 | 判定与全身发力 |
|---|---|---|
| 蓄压喷吐 | 0.84 / 0.30 / 1.12 秒 | 根冠展开、身体后移压低、囊体鼓胀、喷口回收；攻击阶段第 0.10 秒囊体收缩并向上伸展、喷口前甩，发射一枚孢弹；身体反冲，叶片滞后回摆后归位 |
| 囊体横甩 | 0.48 / 0.28 / 0.86 秒 | 根部撑宽、躯干反向压缩；快速伸展茎部、整个囊体向前甩出，喷口和叶片跟随；前侧根部承重、囊体回弹；有效帧为攻击阶段 0.075–0.19 秒，一次攻击最多造成一次 1 点伤害 |
| 呼吸与警觉 | 警觉 0.34 秒 | 呼吸牵动囊体、喷口、叶片和根冠；发现目标时抬身、竖起喷口、展开支撑 |
| 转身 | 0.32 秒 | 先压低重心、根冠撑开，身体收窄后转向，再展开；攻击与收招中不会瞬间掉头 |
| 轻击破韧 | 0.65 秒硬直 | 顺受力方向折身，囊体压缩，喷口反向回摆，叶片延迟摆动，根部补撑；仅破韧时取消攻击 |
| 重击破韧 | 0.70 秒硬直 | 破韧后使用更大的侧倾、根部抬起与囊体失衡；按实际击退落地后回正 |
| 被弹反 | 0.70 秒硬直 | 横甩被弹反时，喷口被掀起、囊体拉长，根部离地并向后失衡；远程弹体仍使用现有反射机制，命中喷吐者削韧 25，破韧时触发重受击 |
| 死亡 | 1.15 秒 | 囊体顺受力方向倾倒、喷口和叶片萎垂，根部仍连接；空中死亡保留对地形的碰撞并下落，末段淡出；立即停止攻击和受击，死亡只上报一次 |

动作切换从上一姿态短暂混合。蓄力、释放、反冲与回正有不同速度；不是对整张图片统一摇摆。使用根冠、茎部、囊体、喷口和叶片组成的剪纸骨架，根冠采用整块原图变形，未新增逐条根须的 Spine 动画资源。

## AI 与判定

- 初始感知距离 420，脱战距离 510，失去视线记忆 0.9 秒；隔墙不会启动攻击。
- 水平距离 ≤ 73 且高度差 ≤ 46 时横甩；76–420 时喷吐。两个招式独立冷却：喷吐 2.25 秒、横甩 1.85 秒；都保留完整收招。
- 喷吐准备的最后 0.22 秒锁定落点，加上释放前 0.10 秒，共有约 0.32 秒固定瞄准窗口。横向朝向从起手锁定，绕背不会让攻击瞬间掉头。
- 受击、弹反、失去有效玩家或离地会取消尚未释放的攻击。已经发出的弹体继续由遭遇控制器管理。
- 喷弹出口由 `SporePose` 在物理时刻计算，视觉使用同一套姿态；发射前检查身体到喷口之间的地形，防止喷口伸到墙后产生弹体。
- 弹道修正：锁定玩家当时的实际受击框中心，喷口在囊体压缩、转动时仍对准这个世界坐标。弹体从真实喷口沿该方向匀速直飞，离口后不追踪；短尾迹指示飞行轴，取消旋转光环。弹反后重新确定一次返回方向，此后同样直飞。
- 不改变碰撞体缩放。生命为 8，韧性为 30；未破韧时可顶着轻击继续喷吐或横甩，失衡期间追打不刷新硬直，结束后有 0.75 秒抗削韧时间。孢弹速度仍为 155、普通伤害 1、反射伤害 2，沿用现有玩家战斗接口。

## 文件职责

- `SporeTuning` / `data/spore_behavior.tres`：可在 Inspector 中调整的物种参数，共享数据只读。
- `SporeBehavior`：感知、选招、瞄准锁定、冷却、受击与运动请求，通过局部信号请求动作和发射。
- `SporePose`：纯姿态采样与喷口位置计算。
- `SporeVisual`：图集分件、关节层级、动作混合、警示及喷吐碎屑。
- `CombatEnemy`：物理移动、生命、伤害去重、死亡及遭遇信号；只增加孢囊组件接线和对应分支。

- `tests/scene/test_spore_behavior.gd`：近远选招、独立冷却、朝向及瞄准锁定、蓄力无伤害、横甩一次命中、喷弹一次释放、受击取消、墙体遮挡、丢失目标、轻重受击、弹反、死亡去重及空中死亡落地；左右朝向各动作连续采样检查有限变换、身体各部位参与发力、重复采样稳定、视觉与物理喷口一致，共 8107 项断言通过。
