# 平台镜头跟随规则

适用入口：`scenes/app/main.tscn → scenes/levels/Level_main.tscn → Level01`。嵌入的 `Level02` 使用同一个玩家、镜头和生命周期，不另设固定房间镜头。

2026-09-06 分区版：正式 Level01 已取得独立场景 UID，Main 使用正式路径引用，保留旧副本内容；不能再次复制场景 UID。相机采用七个关卡区域确定楼层和观察范围。`docs/main_camera_audit.md` 是此前的问题记录，本文件说明当前实现。

## 主要地板

`TerrainPiece.camera_main_floor` 是 Inspector 中的显式标记。当前只标记：

| 节点 | 作用 | 世界碰撞表面 Y |
| --- | --- | --- |
| `Level01/Geometry/Terrain/StartFloor` | 用户指定的 StartFloor1 | 475.5 |
| `Level01/Geometry/Terrain/Floor2` | Level01 独立运行的上层主地板；组合时禁用 | 3.5 |
| `Level01/Level02/Geometry/Terrain/UpperTerrain/Ground13` | 组合上层左段，x=-262..200 | 3.5 |
| `Level01/Level02/Geometry/Terrain/UpperTerrain/Ground14` | 组合上层右段，x=284..1082 | 3.5 |

表面采用实际 CollisionPolygon2D 的世界范围，包含子节点偏移与缩放。上述地板为水平矩形；不要把斜坡/不规则多层多边形标记为主地板后把包围框顶边当作局部脚下表面。禁用碰撞的参考 Floor2 返回空范围，不填补 Ground13/14 中间缺口。浮空平台不建立新的主地板底限。

正式关卡按脚底所在区域取得主地板，不再要求先踩一次地板。出生、检查点重生、浮台和空中进入上层，都直接解析目的地区域。Ground13/14 两段同属上层，HardFloor01 延续区域至 x=1124；浮台继承楼层，不新增主地板。实际跨过地表或从合法连接离开后释放旧底限。

没有 CameraRegions 的场景，或显式关闭 `regions_enabled` 时，才使用原先的碰撞取得/32 px 出生探测回退规则。

底限生效时，最终画面底部不得低于地表，角色脚部接近画面底部。此时不要求纵向 45% 构图。刚离开主地板时，下落脚部上限从底边在约 0.1 秒内过渡到 80%，避免为了瞬间腾出 20% 底部空间而跳镜。自由下落正常跟随；边界与完整主体可见性优先于构图比例。

操作提示与反馈消息位于顶部 HUD 的中间列，随可用宽度换行；不再占用底部角色站立区域。该布局在 1344×640 和 1000×600 视口验证，保持左右状态卡与中间提示互不重叠。

## 关卡区域与编辑

`features/level/camera/main_camera_regions.tscn` 实例化在 Level01 下。每个 `CameraRegion2D` 的 Inspector 字段及编辑器色框可调整区域；坐标经过节点世界变换，不在角色控制器中硬编码。

| 区域 ID | 脚底归属范围（Level01 局部坐标） | 显示左右界 | 主地板/构图 |
| --- | --- | --- | --- |
| `lower_room` | x=-256..1370，y=3.5..704 | -326..1370 | StartFloor；宽阔处前视 |
| `upper_room` | x=-262..1124，y=-1216..3.5 | -334..1370 | Ground13/14；独立 Level01 回退到 Floor2 |
| `right_connection` | x=1124..1370，y=-140..435 | 880..1370 | 居中并向上层入口预构图；底层兜底为 StartFloor |
| `right_floor_exit` | x=1370..1614，y=3.5..704 | 1000..1614 | 真正穿过右墙外侧后才进入；StartFloor |
| `west_branch` | x=-1024..-262，y=-1216..704 | -998..0 | 独立横向观察范围，不新增主地板 |
| `east_mechanism` | x=1124..1792，y=-1216..3.5 | 1056..1792 | 机关区居中，不新增主地板 |
| `floor_opening` | x=200..284，y=-43..117 | -334..1370 | 仅真实下落且通道未被 World 碰撞封堵时选用 |

区域重叠时采用最高 `priority`。`activation_rect` 决定空间归属，`horizontal_limits` 限制整屏显示，不要把窄通道宽度直接当作视口宽度。右连接的 `horizontal_guard_rect=(1124,10,246,425)` 对应实际墙体高度，禁止看到 x=1370 外的区域。墙体本身可以显示。

移动接近高优先级连接区时，边界和居中权重提前混合；静止或反向离开不会被邻区吸引。释放连接区后，按移动预算平滑进入外区。右墙下方仍归下层房间，避免在 x=1300 起跳穿过 y=435 时横向跳镜。

`floor_paths` 使用实际主地板表面。`transition_floor_path` 为向上跨层的预构图目标。开口对角色宽度内的三处 World 射线进行检查，包含移动方块；不会把按钮激活等同于洞已打开。Ground13/14 中间的原方块运动保持不变。

如果视口比区域的显示宽度更宽，会对称拓宽显示范围以容纳整屏，不能强行夹入不足一屏的矩形。高处玩家接近或超过原全局上界时，只调整运行时顶部安全界以保持主体可见，重生后恢复；未改变高处锚点位置，也未证明这些点已构成可达路线。

## 构图、时序和参数

`features/level/camera/forward_camera_framing.gd` 的导出字段集中保存镜头参数：

| 字段 | 默认值 | 含义 |
| --- | --- | --- |
| `front_view_ratio` | 0.8 | 非边界稳定前视比例，左右对应玩家 20%/80% |
| `vertical_player_ratio` | 0.45 | 未受主地板底限限制的稳定脚部位置 |
| `turn_confirmation_time` | 0.1 s | 持续反向意图才改变观察方向 |
| `turn_smoothing_time` | 0.16 s | 前视偏置的指数平滑时间常数，并非完整转向时间 |
| `vertical_smoothing_time` | 0.05 s | 相机世界中心的纵向指数平滑时间常数 |
| `falling_player_max_ratio` | 0.8 | 非主地板/世界边界处的下落脚部最深位置 |
| `intent_dead_zone` | 0.1 | 已接受控制意图的微小输入过滤 |
| `floor_contact_tolerance` | 2 px | 实际站立接触与地表的几何容差 |
| `regions_enabled` | true | 启用当前关卡的分区限制 |
| `region_transition_time` | 0.12 s | 区域边界、居中权重与水平锚点的平滑时间常数 |
| `region_pan_speed` | 600 px/s | 分区平移速度预算；角色更快时允许同步其实际位移，安全约束仍优先 |
| `region_approach_distance` | 96 px | 向相邻入口移动时的提前混合距离，高速时适当增加 |
| `rising_top_ratio` | 0.2 | 上升时主体到达画面顶部 20% 带才继续向上带镜 |

玩家先在物理帧移动，Framing 在优先级 200 读取真实位移及只读控制意图，平滑后约束主体与主地板可见范围，再把中心换算为 `PhantomCamera2D.follow_offset`。Host 在优先级 300 应用结果。双轴死区、插件阻尼、lookahead 和 Camera2D 自身平滑关闭，避免约束结果被二次平滑改变。

普通行走和摆荡读取已接受的水平操作；攀爬读取本帧实际路径方向，避免 velocity 清零丢失意图；主动伸腿可改变前视，自动回收和被动漂移不会翻向。镜头不修改玩家运动、能力状态或碰撞。

## 出生、重生与检查点

`HandbuiltLevel.spawn_camera_direction` 配置初始朝向，默认右。检查点保存到达时已确认的前视方向。重生先重置玩家及物理插值，再直接解析目的地区域、显示范围和主地板，清除方向计时器/位置历史，发布即时构图并调用插件 teleport 接口。下层检查点 `(329,438)` 不依赖 32 px 地板探测。插件 0.11 的虚拟节点原始位置也需同步，避免下一帧 FRAMED 重复应用位移；实际 Camera2D 的位置仍由 Host 写入。

## 验收

- `tests/scene/test_camera_regions.gd`：正式默认入口/F6 场景身份、检查点首帧与实际落地、两层主地板短跳、合法低通道空中位置的三种到达历史、Ground11 实际落地、右通道及右墙下方真实起跳、邻区外停留/离开、真实开放边缘下落、堵洞方块碰撞与运动、高处主体安全、900 px/s 镜头轨迹。
- `tests/scene/test_phantom_camera_integration.gd`：显式关闭分区，单独验证通用 20%/80% 构图、意图、防抖/转向、下落、45% 收敛、缩放和世界四边。压力位移是冻结玩家物理后的镜头夹具，不能当作真实落体。
- `tests/scene/test_camera_main_floors.gd`：显式关闭分区，单独验证碰撞主地板回退行为、真实站跳、浮台和开放边缘。
- 独立 `level_01` 与默认入口启动；主组合/HUD/玩家和地板相关回归。

所有比例均使用实际视口 canvas 变换或 Camera2D 的 screen center；几何期望独立从碰撞节点计算。场景底限限制的是可见地表，不保证所有任意位置的落点都提前可见，必经跳跃仍须正式关卡试玩。
