# 白盒实体行为规则

以下规则对应当前 JSON 目标矩形驱动实现。2026-09-05 的机制修复补齐了 B1、B2、B4 的目标引用；关卡布局、实体 IID 与目标坐标保持原数据。历史按固定铰点描述的实现已由本表替代。世界坐标包含 level 的 worldX/worldY 偏移。

## 按钮与方块

| 按钮 | 目标 | 初始矩形 → 终点矩形（x,y,width,height） |
| --- | --- | --- |
| B1 (448,304) | C1 | (480,240,32,64) → (528,304,64,32) |
| B2 (144,304) | C2 + C6 | C2：(592,176,16,144) → (608,320,144,16)；C6：(560,240,32,16) → (672,288,16,32) |
| B3 (672,144) | C5 | (176,288,32,16) → (176,304,32,16) |
| B4 (0,160)，保存于 Level_1 | C3 + C4 | C3：(160,-128,32,80) → (160,16,32,96)；C4：(48,-128,32,128) → (48,16,32,128) |

- Button 的 Entity_ref 引用实际移动方块；该 MoveableCube 的 Entity_ref 引用唯一终点标记。空按钮引用或有终点但无控制按钮的方块会报告数据问题。
- 按钮采用单次锁存；按住、重复接触和再次触发不会叠加运动，R 重开恢复初始状态。
- 运动先短暂视觉抖动，再按平滑曲线移动。旋转使用初始和终点变换求得的圆弧；B2 的 C2、C6 使用共同运动时长，整个旋转过程中保持刚性相对位置。当前数据导出的共同铰点为 (600,328)。
- 终点 MoveableCube 不创建重复实体；紧贴终点底边的 Ring 也是编辑用终点标记，不创建额外可钩挂点。
- B4 控制平台上的实际 Ring 在运动完成前隐藏且不可钩挂，完成后开启。Ring 随平台移动，平台尺寸变化时仍贴合底边。C3 在本数据中从 80 像素变为 96 像素高，画面和碰撞同步更新。
- 实体可视与碰撞边界采用 JSON 实例尺寸；按钮交互范围额外向上延伸 6 像素。

## 其他实体与能力

- Ground：一般地块，允许扎根；HardFloor：实体地块，禁止扎根。
- Damage / DamageMachine：接触即死；DamageMachine 暂用左右各 32 像素、64 像素/秒行程。
- Door：当前仍为普通实体方块，不承担出口完成条件。
- Frog：毒雾。速度倍率在约 1 秒内从 1.0 降至 0.55，离开后约 1 秒恢复；稳定度消耗、恢复及枯萎遵循 GDD。
- Ring：仅成熟期可连接，候选列表仅包含已经开放的锚点。
- Wind：按 JSON 边界持续向左吹，墙体和移动方块遮挡实际风力与风效。
- 营养液/毒液：按住 E 连续吸收。达到一次阶段阈值即结束本轮吸收，显示“松开 E 后继续吸收”；必须释放再按下才能继续。离开并重新进入液体不会绕过该限制。
- 音效为场景局部的事件监听，不驱动玩法。玩家与关卡声音各限制为 6 个声部；脚步仅在实际地面移动时播放，吸收音有间隔，锁存按钮重复触发不重播。

## 验证入口

- tests/scene/test_json_whitebox_level.gd：四个按钮引用与运动终点、B2 中途刚性、B4 Ring 前后门控、变尺寸挂点。
- tests/scene/test_absorption_session.gd：长按 E 不连跳阶段、释放后可继续、离开资源后不绕过限制。
- tests/unit/test_resource_controller.gd：毒区速度渐变与资源数据。
- tests/scene/test_player_audio.gd：真实移动、跳跃落地、形态与能力事件，站立静音和吸收节流；图形模式用于实际音频播放验收。
