# 白盒实体行为规则

本文档记录从 `Yiguang.json` 白盒数据中确认的按钮与可移动方块行为。坐标使用白盒源数据中的世界像素坐标；`B` 表示 `Button`，`C` 表示 `MoveableCube`。

实体语义以白盒设计确认结果为准；实例尺寸优先于实体定义尺寸。本文档不回写或重排 `Yiguang.json` 的原始结构。

## 已确认规则

| 按钮 | 目标方块 | 按下后的行为 |
| --- | --- | --- |
| `B1`（`Level_0`，`(448,304)`） | `C1`（`Level_0`，`(480,240)`，`32×64`） | 以右下角 `(512,304)` 为铰点顺时针旋转 `90°`，直到与地面齐平。 |
| `B2`（`Level_0`，`(144,304)`） | `C2`（`(592,176)`，`16×144`）+ `C6`（`(560,240)`，`32×16`） | 以 `C2` 左上角 `(592,176)` 为共同铰点，二者联动顺时针旋转 `90°`，直到风区不再被阻隔。 |
| `B4`（贴在 `Level_0` 左侧边界墙的右侧，坐标 `(-16,160)`） | `C3`（`Level_0`，`(160,0)`，`32×80`）+ `C4`（`Level_0`，`(48,0)`，`32×128`） | `C3`、`C4` 初始隐藏在更高处，玩家无法触碰；按下 `B4` 后下降到当前白盒位置，允许成熟期玩家使用钩索/藤蔓连接。 |
| `B3`（`Level_0`，`(672,144)`） | `C5`（`Level_0`，`(176,288)`，`32×16`） | 按下 `B3` 后向下移动，直到与地面齐平。 |

## 待确认规则

按钮是否可逆以及其余方块的移动方式，均以之后的逐项确认结果为准。

## 实施默认值（待设计复核）

- 白盒 JSON 中的 `C3`、`C4` 和 `C5` 坐标作为机关运动终点。`C3`、`C4` 初始向上偏移 `160` 像素；`C5` 初始向上偏移 `128` 像素，按下 `B3` 后回到 JSON 坐标 `(176,288)`。该坐标使 C5 的下边缘贴合 y=`304` 的已确认地面顶边。
- 按钮为单次锁存触发；重开关卡后恢复初态。重复按下不会叠加运动。
- 按钮的可视矩形和 `button_size` 严格使用 JSON 实例尺寸；为让角色站在按钮所在平台时可触发，Area2D 交互范围仅向上额外延伸 `6` 像素。
- C2 与 C6 共享由较长圆弧行程决定的旋转时长；二者以同一铰点同步旋转，整个过程保持刚性相对位置。
- `DamageMachine` 临时采用左右各 `32` 像素、速度 `64` 像素/秒的往返范围，等待设计提供端点与速度。

## 已确认的其他实体语义

- `Ground`：一般地块。
- `Damage`：一击毙命地块。
- `HardFloor`：玩家不能在其上扎根的地块。
- `Door`：可移动方块，暂按普通地块处理，不作为最终出口。
- `Frog`：毒雾，具体影响遵循 GDD 中的毒素环境规则。
- `DamageMachine`：左右移动的伤害机器（例如锯子），接触后一击毙命。
- `Ring`：成熟期长藤蔓可以钩住的环形锚点。
- `Wind`：白盒中的风环境区域标记；区域范围以 JSON 实例尺寸为准，实际风力传播不能穿过世界墙体。

## 关卡归属说明

- `B4` 虽然在 JSON 的相邻 `Level_1` 数据块中保存，但设计语义是贴在 `Level_0` 左侧边界墙的右侧的跨区按钮；它控制 `Level_0` 的 `C3`、`C4`，这是有意的跨区机关。
- 实体实例尺寸优先于实体定义尺寸；导入和运行时不需要以定义尺寸覆盖实例尺寸。
