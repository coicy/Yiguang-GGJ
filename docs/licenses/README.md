# 素材许可证登记

本目录保存运行时外部音频的许可证登记和官方来源链接。许可证适用于具体素材包，不代表来源网站上的所有内容都具有相同许可。

## 比赛提交建议

- 提交包中保留本目录和 `docs/credits.md`。
- 在游戏页面或提交说明中列出素材作者、来源链接和许可证。
- CC0 不强制署名，但保留 Kenney、Fantozzi、qubodup 的来源记录更利于审核。
- 只要某个文件仍列在 [UNVERIFIED.md](UNVERIFIED.md)，就不要将它用于最终导出或提交截图/视频。
