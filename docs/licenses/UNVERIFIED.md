# 尚未核实许可证的素材

以下文件在仓库历史中被引入，但目前没有找到足够可靠的原始下载页和许可证证明。它们不能仅因为“免费”或来自某个素材网站就视为可用于比赛。

- `Wind.ogg`、`Wind2.ogg`、`Wind3.ogg`
- `Kim Lightyear - Magic Tales*.wav`
- `No More Magic.ogg`
- `magical_1.ogg` ~ `magical_7.ogg`
- `button press 1.wav`
- `jumpland.wav`

## 应该到哪里找

1. 回到最初下载这些文件的网站或下载页面。
2. 打开素材包内的 `LICENSE.txt`、`README.txt`、作者说明或下载页的 License 字段。
3. 记录确切的素材页 URL、作者、许可证名称和下载日期。
4. 如果来源页只写“free”或“free to use”，但没有明确许可条款，不要用于最终提交。
5. 如果是 Freesound，必须核对具体音频条目的许可证，不能只看网站总规则；CC0、CC BY、CC BY-SA 的署名/继承要求不同。

在完成核验前，建议不要把这些文件配置到 `SoundDefinition`，也不要把它们作为比赛成品中的音频使用。
