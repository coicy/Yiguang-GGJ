# Kenney 音频素材许可记录

## 官方许可

Kenney 的以下官方素材页都标示为 `Creative Commons CC0`：

- [Impact Sounds](https://kenney.nl/assets/impact-sounds)
- [RPG Audio](https://kenney.nl/assets/rpg-audio)
- [UI Audio](https://kenney.nl/assets/ui-audio)
- [Music Jingles](https://kenney.nl/assets/music-jingles)

Kenney 官方支持页还明确说明：素材可以用于商业项目，且不要求署名；如果主动致谢，可以提及 `Kenney`，但不要使用 Kenney 的官方 Logo。

- [Kenney 官方支持页：Can I use the game assets in a commercial project?](https://kenney.nl/support)

## 本项目使用的文件

- `Impact Sounds`：`footstep_grass_000/001/002.ogg`、`footstep_concrete_000/001.ogg`、`impactSoft_medium_000.ogg`、`impactSoft_heavy_000.ogg`、`impactWood_medium_000.ogg`
- `RPG Audio`：`cloth1.ogg`、`cloth2.ogg`、`clothBelt.ogg`、`beltHandle1.ogg`、`metalLatch.ogg`、`creak1.ogg`、`handleCoins2.ogg`
- `UI Audio`：`click3.ogg`
- `Music Jingles`：`jingles_PIZZI00.ogg`、`jingles_PIZZI02.ogg`、`jingles_PIZZI06.ogg`

当前走路音效测试场景实际引用的是 `Impact Sounds` 中的 `footstep_grass_000/001/002.ogg`。
